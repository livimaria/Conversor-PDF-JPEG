## 🎯 Objetivo

Este conversor tem o objetivo de tranformar PDFs em JPEG, nele podem ser colocados até 5 arquvivos em PDF e todos irão ser convertidos para JPEG de uma única vez, ficando dentro um arquivo .zip, pronto para se baixado.
Esse conversor foi feito para uma empresa onde prestei serviços, onde eles utilizavam uma outra ferramenta para fazer essa conversão, porém o mesmo tinha um limite de documentos para serem carregados, então eles me solictaram que fosse feito um conversor que atendesse o pedido deles.
